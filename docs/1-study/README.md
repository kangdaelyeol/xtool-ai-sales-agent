# 음성 AI 상담원 해부: xtool-ai-sales-agent로 배우는 실시간 음성 에이전트

이 폴더는 이 레포(오리지널스 AI 음성 영업 상담원)를 교재로 삼아 **실시간 음성 AI 에이전트가 어떻게 동작하는지**를 처음부터 끝까지 설명하는 학습서입니다. 코드가 "무엇을 하는지"에서 멈추지 않고, 그 밑에 깔린 **개념·이론·기법**과 "왜 그렇게 만들었는지"까지 다룹니다.

- **대상:** 개발 경험은 있지만 음성 AI(오디오, STT, TTS, 턴 테이킹, 실시간 전송)는 처음인 사람
- **분량:** 17개 장, A4로 대략 460∼490쪽. 그중 "깊이 보기" 하위 절(바이트·비트 구조, 손 계산, 실측)은 처음 읽을 때 건너뛰어도 흐름이 이어집니다. 장마다의 글자 수와 읽는 시간은 아래 "걸리는 시간"에 있습니다(2026-11-08 갱신)
- **실습:** [lab/](lab/) 폴더의 스크립트를 레포 루트에서 `node docs/1-study/lab/<파일>`로 돌리면 본문의 실측 값을 키 없이 직접 재현합니다. 전체 목록과 추천 순서는 [17-4절](17-glossary-and-next.md#17-4-직접-해-보면-좋은-실습)에 있습니다(2026-11-05 추가, 2026-11-06 갱신)
- **기준:** 이 레포 코드와 `@livekit/agents` 1.9.5. 처음 쓴 기준은 2026-11-03의 코드이고, 그 뒤 바뀐 코드는 [CHANGELOG.md](CHANGELOG.md)의 각 항목에 적은 기준으로 따라 고쳤습니다. SDK 내부 설명은 설치된 패키지의 소스를 읽어 확인했고, 코드 위치를 함께 적었습니다.
- **변경 이력:** 레포가 바뀔 때마다 따라 고치고 [CHANGELOG.md](CHANGELOG.md)에 남깁니다. 마지막 반영 기준과 다음 갱신 절차도 거기에 있습니다.

## 표기 약속

- **코드 위치:** 프로젝트 파일은 링크(예: [src/main.ts](../../src/main.ts))로, SDK 파일은 `node_modules/@livekit/agents/src/` 기준 경로(예: `voice/audio_recognition.ts`)로 적었습니다. 실제로 실행되는 것은 같은 패키지의 `dist/*.js`입니다.
- **확인 수준:** SDK 코드로 확인한 동작과, 코드 흐름으로 추론했지만 실측이 필요한 동작을 구분해 적었습니다. 후자는 본문에 "확인 필요", "추정", "실측으로 확인할 항목"이라고 표시했습니다.
- (2026-11-08 추가) **범위:** 본문의 범위는 0.3∼0.5초처럼 `∼`(U+223C, 물결 연산자)로 잇습니다. 키보드의 `~`로 쓰면 GitHub가 한 문단 안의 두 `~` 사이를 취소선으로 그립니다. 코드 블록(그림·실습 출력)과 인라인 코드 안에서는 `~` 그대로입니다.
- **수치:** 지연·정확도 숫자는 [5-poc-results.md](../5-poc-results.md)의 PoC 측정(맥, 서울 → 해외 API)에서 가져왔습니다. 환경이 바뀌면 달라집니다(13-7절).
- **버전:** 모델 이름, SDK 동작, 가격은 자주 바뀝니다. 코드를 고치기 전에 LiveKit 문서(`lk docs`)와 공급사 문서를 다시 확인하세요.
